# FeiHou-Ai-Studio

花果山AI灵境坊 Windows 客户端 `2.1.8` 增量更新。

## 获取更新

- 已接通在线更新的客户端：打开启动器更新面板，检查更新、下载并安装。
- 需要手动更新的客户端：下载 `FeiHou-Windows-2.1.8-update.zip`，在启动器更新面板中选择本地更新包并安装。
- 本更新包的最低兼容版本是 `2.1.0`，不能作为独立安装包运行，也不要手动解压到程序目录。
- 安装前请完成或停止正在运行的生成任务；更新器会保留 API 配置、模型列表、画布、素材和生成结果。

## 本次更新

- 修复 H3 Turbo 模型设置中主模型、CLIP、视频 VAE、音频 VAE、二次采样模型、语义桥模型和二采放大模型无法选择的问题。
- 修复首轮采样 LoRA 和二次采样 LoRA 无法搜索选择的问题。
- 版本号升级为 `2.1.8`，支持从 `2.1.0` 开始累计升级。

## 安全

此仓库不存放个人 API Key、用户素材、运行缓存或更新签名私钥。

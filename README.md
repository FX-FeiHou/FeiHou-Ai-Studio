# FeiHou-Ai-Studio

本仓库发布花果山AI灵境坊 Windows 与 macOS 客户端的安装包、版本清单与说明。

## 客户端下载

- [GitHub 完整安装包](https://github.com/FX-FeiHou/FeiHou-Ai-Studio/releases/download/v1.6.7/FeiHou-Ai-Studio-Win-1.6.7-full.zip)
- [夸克网盘下载](https://pan.quark.cn/s/327190b9484c)

## 首次安装

打开 [完整安装包发布页](https://github.com/FX-FeiHou/FeiHou-Ai-Studio/releases/tag/v1.6.7)，选择 `FeiHou-Ai-Studio-Win-1.6.7-full.zip`。完整解压后双击“花果山AI灵境坊.exe”，保留同目录的 app 文件夹。API Key 需自行填写。

GitHub 自动生成的 Source code ZIP/TAR 是发布说明仓库，不是客户端。

## 获取更新

从 [Releases](https://github.com/FX-FeiHou/FeiHou-Ai-Studio/releases/latest) 下载发布文件。

- 已接通在线更新的客户端：打开启动器更新面板，检查更新、下载并安装。
- 尚未配置在线更新的旧客户端：先安装 1.6.7 完整包，再下载 `FeiHou-Windows-1.6.8-update.zip`，在启动器更新面板中选择本地更新包并安装。
- 更新包适用于已有完整程序文件夹的 Windows 客户端，不能作为独立安装包运行；不要手动解压到程序目录。
- 安装前完成或停止正在运行的生成任务；更新会保留 API 配置、模型列表、画布、素材和生成结果。

## macOS 版

macOS 版请到对应的 macOS 完整包发布页下载。它使用独立的 macOS 更新清单，不影响 Windows 客户端更新线路。

## 安全

此仓库不存放个人 API Key、用户素材、运行缓存或更新签名私钥。

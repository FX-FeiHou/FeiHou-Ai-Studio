# FeiHou-Ai-Studio

花果山AI灵境坊 Windows 客户端 `1.6.9` 增量更新。

## 获取更新

- 已接通在线更新的客户端：打开启动器更新面板，检查更新、下载并安装。
- 需要手动更新的客户端：下载 `FeiHou-Windows-1.6.9-update.zip`，在启动器更新面板中选择本地更新包并安装。
- 本更新包的最低兼容版本是 `1.6.8`，不能作为独立安装包运行，也不要手动解压到程序目录。
- 安装前请完成或停止正在运行的生成任务；更新器会保留 API 配置、模型列表、画布、素材和生成结果。

## 本次更新

- 修复部分下载或解压后的客户端因 WebView2 程序集阻止标记而无法启动的问题。
- 启动器与应用版本统一为 `1.6.9`。

## 安全

此仓库不存放个人 API Key、用户素材、运行缓存或更新签名私钥。
